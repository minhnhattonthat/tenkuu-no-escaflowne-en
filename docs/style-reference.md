# Style reference

The voice every line is judged against. Pairs are from the shipped script.

## Voices
| Speaker | JP markers | English devices |
|---|---|---|
| Hitomi | あたし/私, 〜じゃない, 〜よ, ちゃう, がんばり語 | Modern teen: contractions, "Huh?", "you know", "No way". Thoughts: no quotes. Uses "-san" for Allen, Folken, Millerna; bare "Van" |
| Van | 俺, 貴様, 〜だ, 〜ぞ, 兄上 | Short, blunt, hot-tempered: "Damn it!". Softens only for Merle ("Sorry I worried you") |
| Merle | メルル as "I", バァン様, ミャー, ふみぃ | Third person "Merle" when the JP does it; "Van-samaaa"; "Meow", "Mew"; insults Hitomi freely |
| Allen | 私, 〜たまえ, 〜ですかな, 〜しよう | Courtly, measured, a little teasing: "Make yourself at home", "Think nothing of it", no contractions when formal, some when kind |
| Millerna | 〜ですわ, 〜ましてよ, わたくし | Refined, princessly: "Oh my", "do forgive me", "you know". かしら as "I suppose", "perhaps" |
| Dryden | 俺, 〜ねぇ, 〜ぜ, 〜わ, オラー | Loose, wry, teasing: "Beats me!", "Honestly", "what I want, I get". Never formal |
| Folken | 私, 〜だ, 〜のだ, 〜か | Calm, spare, faintly archaic: "Very well", "I have come for you" |
| Dornkirk | 〜おる, 〜のだ, 〜よ, フフフ | Old, grand, unhurried: "Behold", "I see it", "Girl"; no contractions |
| Dilandau | 僕, 〜だよ, 〜ちゃう, 〜ねェ | Sing-song cruelty: "Oopsie, I hit it", "you got caaaught"; drawn-out vowels kept |
| Gaddes, soldiers | 〜やす, 〜ですぜ, お頭 | Rough and friendly: "Sure thing", "Boss", "Your Majesty", "we got trouble" |
| Mole Man | あっし, 〜なさる, ひへへ | Sly, dropped letters: "have ya", "'course", "Hee hee" |
| Ispano chief | broken: 払えなければ、我々帰る | Pidgin kept: "No can pay, we go home." |
| Duke of Freid, Boris, King Aston | 〜である, 貴様, ござる | Old court formal: "Shed no tears", "As you command" |
| Naria, Eriya | 〜だよ, 〜ね, ご主人様 to Folken | Tough and playful in the field, soft and formal with Folken ("We were so lonely") |
