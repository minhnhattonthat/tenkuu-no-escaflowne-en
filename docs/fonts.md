# Fonts

Every font or glyph sheet the build reads ends up inside the released patch, so its licence must allow that. One row
per file; a font with no known licence doesn't go into a release.

| File | Source (URL, version) | Licence | Redistributable in a patch | Used for | Changes made |
|---|---|---|---|---|---|
| fonts/vwf.txt | drawn for this project | MIT, same as repo | yes | dialogue and menu VWF, staff roll, title copyright row | - |
| fonts/LiberationSerif-Bold.ttf | Liberation Fonts 2.1.5, github.com/liberationfonts/liberation-fonts (`fonts/Liberation-LICENSE.txt`) | SIL OFL 1.1 | yes | chapter cards | none; pixels only ship |
| fonts/Cinzel-Variable.ttf | Cinzel, github.com/google/fonts `ofl/cinzel` (`fonts/Cinzel-OFL.txt`) | SIL OFL 1.1 | yes | title logo | none; pixels only ship |
