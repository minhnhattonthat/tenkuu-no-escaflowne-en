# Glossary - Tenkuu no Escaflowne (The Vision of Escaflowne)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: kept, hyphenated (Van-sama, Hitomi-san). Name order: Western (given name first).
- Romanisation source: official English names (Bandai Entertainment anime release) where they exist, else an earlier fan patch (none exists), else Hepburn without macrons.
- Credits: English.
- Register / flavour: to be set in phase 6. Sound effects: to be set in phase 6.
- Abbreviations: full names and terms everywhere, prefer engine changes over shortening.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ and … -> ..., ！？ -> ?!
- Voice notes: to be filled in phase 6, from `docs/style-reference.md` if one is written.
